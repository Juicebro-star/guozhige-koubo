# 果汁哥 · 白菜价数字人口播

## 什么时候用

用户要一条**竖版（9:16）数字人口播**：一个"人"对着镜头讲 15 秒，带花字、关键词变色、二维码。

## 流程（五步）

1. **改稿 + 换人物** → 编辑 `pipeline/config.json`（`script` / `avatar` / `look` / `title` / `keys` / `big` / `stack` / `pill`）
2. **出提示词** → `python3 pipeline/1_prompt.py`
3. **生成** → 用户在秘塔 H3 控制台按提示词生成（9:16 / 768P / 15 秒，约 1.35 元），下载 mp4
4. **出片** → `bash pipeline/2_make.sh <成片.mp4>`
5. **发布文案** → 按平台给（抖音/视频号/X 三套逻辑不同）

详细说明见 `pipeline/README.md`。

## 换风格（不重新生成，0 成本）

同一段素材可以出不同花字风格，`pipeline/variants/` 里是现成的配置：

```bash
cd pipeline
CONFIG=variants/A.json bash 2_make.sh ~/Desktop/h3.mp4   # 克制真人风
CONFIG=variants/B.json bash 2_make.sh ~/Desktop/h3.mp4   # 清单干货风
```

## 这个 skill 是自包含的

`SKILL.md` + `persona.json` + `assets/` + `scripts/` + `references/` + `templates/` + `pipeline/`，拷走整个目录即可用（约 10MB，不含运行时依赖）。
首次 `2_make.sh` 会在 `pipeline/work/` 里装渲染依赖（约 1 分钟，之后复用）。

## 硬规则

- **单段不超过 15 秒**：H3 从 16 秒起按 2 倍计费。稿子 60–67 字。
- **稿子不超过 67 字**：4.5 字/秒，超了要么剪、要么重写。
- **不编数字、不编经历**：没有的成交案例不要写成"有人靠这个月入 X"。
- **必须标注 AI**：画面角标 + 平台声明（视频号强制）。
- **只用有权使用的脸和声音**：不用明星、不用他人未授权素材。
- **二维码要黑版**：橙色二维码对比度不足，压缩后可能扫不出。

## 稿子写法（吃过一次的教训）

- 别用「不是 A，是 B」这种否定句式——一眼 AI 味。
- 开头给结果或场景，别铺垫：「群里天天都在聊：AI 到底怎么用」。
- 中段给三条具体的东西，名词要落地：「工具选型、Agent 搭建、接单变现」。
- 结尾一个动作，不催不逼：「想围观的，扫码进来」。

## 花字配置（config.json）

| 字段 | 作用 |
|---|---|
| `big` | 中段橙色大字，`at` 填稿子里的词 |
| `stack` | 左侧三条逐条弹出，`at` 是各自出现的词 |
| `pill` | 二维码上方胶囊（扫码进群） |
| `keys` | 字幕变色词，必须原样出现在稿子里 |
| `qr_pos` | 二维码在 1080×1920 里的位置 |
| `preset` | 花字强度：克制（真人分享感）/ 标准 / 热闹 |

## 交付前检查

1. 抽 4 帧：有没有烧字幕、脸有没有漂、口型对不对
2. 二维码用另一台手机扫**成片**（不是原图）
3. 时长是否 ≤15 秒
