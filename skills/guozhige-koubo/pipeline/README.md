# 白菜价数字人口播流水线 · 15 秒竖版

一句话：**换一张参考图 + 换一段稿子 → 出一条 15 秒竖版数字人口播成片。**

```
参考图 + 稿子
   │
   ├─ 第1步 改 config.json（人物 / 稿子 / 花字）
   ├─ 第2步 python3 1_prompt.py     → 拿到 H3 提示词
   ├─ 第3步 秘塔 H3 控制台生成        → 下载 mp4（人工，1.35 元/条）
   └─ 第4步 bash 2_make.sh h3.mp4   → 自动出片（对齐+花字+二维码+渲染，约 2 分钟）
```

---

## 第 1 步：换人物、换稿子（只改一个文件）

打开 `config.json`：

| 字段 | 改什么 | 换人物时 |
|---|---|---|
| `avatar` | 参考图路径（9:16 竖图，正脸、闭嘴、头发别挡脸） | **改** |
| `look` | 一句人物描述：年龄/性别/发型/服装/光线 | **改** |
| `act` | 动作风格（一边讲一边做手势之类） | 通常不用改 |
| `script` | 稿子，**≤67 字**（≈15 秒，4.5 字/秒） | 改 |
| `title` | 顶部小胶囊：`{left, right}` | 改 |
| `big` | 中段大字：`{at, text}`，`at` 是稿子里的词 | 改 |
| `stack` | 三条干货清单：`[{t, at, icon}]` | 改 |
| `pill` | 二维码上方胶囊：`{at, text, sub}` | 改 |
| `keys` | 字幕里要变色的词（必须原样出现在稿子里） | 改 |
| `qr` / `qr_pos` | 二维码图片、位置 `{x,y,w}`（1080×1920 坐标） | 一般不动 |
| `preset` | 花字强度：`克制` / `标准` / `热闹` | 一般不动 |
| `gen` | 生成参数：`9:16` / `768P` / `15` 秒 | 一般不动 |

**换人物就两行**：`avatar` 换个图，`look` 换一句描述。别的都不用碰。

---

## 第 2 步：生成提示词

```bash
python3 1_prompt.py
```

输出会告诉你：传哪张参考图、选什么参数、以及一整段可复制的提示词。

拿到提示词去**秘塔 H3 控制台**：

| 项 | 值 |
|---|---|
| 参考图 | `config.json` 里的 `avatar` |
| 比例 / 分辨率 / 时长 | 9:16 / 768P / 15 秒 |
| 时长别超过 15 秒 | 16 秒起按 2 倍计费 |
| 音频输入 / 优先通道 / Context IR | 都别开 |

成本约 **1.35 元/条**（153 积分）。

---

## 第 3 步：一条命令出片

```bash
bash 2_make.sh ~/Desktop/h3.mp4
```

自动做这些事：

1. 抽音轨，检测静音间隙，按标点断句反推**每个字的时间点**（不需要 whisper）
2. 画面规整到 **1080×1920 / 30fps**（H3 出来是 768×1344 / 24fps）
3. 生成 `edit.json`（花字、大字、清单、二维码、胶囊）
4. 渲染成片到 `out/`

第一次运行会自动装依赖（约 1 分钟），之后每条 2 分钟左右。

- 抖音：1080×1920 直接上传

## 目录

```
pipeline/
├── config.json       ← 唯一要改的文件
├── 1_prompt.py       ← 生成 H3 提示词
├── 2_make.sh         ← 拿到成片后一键出片
├── align_lite.py     ← 免 whisper 的逐字对齐
├── gen_edit.py       ← config → edit.json（花字配置）
├── assets/qr.png     ← 二维码（黑版，橙色版压缩后可能扫不出）
├── assets/sfx/       ← 卡点音效
└── out/              ← 成片输出
```

渲染引擎在 `../templates/huazi-916`（Remotion，首次运行会拷到 `work/` 并装依赖）。

## 换人物的三个要点

1. **参考图必须 9:16 竖图、正脸、闭嘴、头发不挡脸**。侧脸或张嘴的图，生成出来会漂。
2. **`look` 写得越具体越稳**：`年轻东亚女性，黑色长发带脸侧碎发，白色罗纹背心，室内自然光`。别写"漂亮女生"这种。
3. 换人之后先跑一条**试片**看看脸，再批量。一条 1.35 元，试错很便宜。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 二维码扫不出来 | 橙色原件对比度只有 1.5:1，视频压缩后失效 | 用 `assets/qr.png`（已转纯黑） |
| 花字跟不上口型 | 语速和 4.5 字/秒差太多 | 稿子控制在 60–67 字，或改 `1_prompt.py` 里的估算值 |
| 画面里有烧字幕 | H3 偶发 | 生成后抽 4 帧验，有就重生成 |
| 成片时长超 15 秒 | 稿子太长 | 减字，或把 `tail` 调小 |
