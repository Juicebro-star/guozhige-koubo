# 换人物

## 1. 准备参考图

- **9:16 竖图**，正脸、嘴闭着、头发不挡脸，光线均匀
- 从视频里取帧时，挑一张表情自然、没有夸张动作的
- 只用本人或明确授权的人的照片

## 2. 改两行配置

`pipeline/config.json`：

```json
"avatar": "../assets/新人物.jpg",
"look": "年轻男性，短发，深色卫衣，室内自然光"
```

`look` 写具体特征（年龄层、发型、服装、光线），别写“漂亮女生”这种模糊描述——H3 会自由发挥。

## 3. 先拍一条试片

`python3 pipeline/1_prompt.py` → 拿提示词去 H3 生成一条 → `bash pipeline/2_make.sh`。

重点看三件事：像不像本人、口型跟不跟得上、动作自然不自然。**一条 1.35 元，试错很便宜，别一次批量。**

## 4. 稳定之后

人物固定后，`look` 就别再改了——同一套描述 + 同一张参考图，才能保证多条片子是同一个人。
